This app reads and saves your list in a private GitHub repo. Paste a GitHub fine-grained token to connect this device. The token is stored only in this browser (localStorage) on this device.

  1. Open github.com/settings/personal-access-tokens/new (sign in to GitHub).
  2. Token name: e.g. To-Do app (iPhone). Expiration: your choice (e.g. 1 year).
  3. Resource owner: your account.
  4. Repository access: Only select repositories → pick mindclip-todos-data only.
  5. Permissions → Repository permissions → Contents: Read and write (Metadata: Read-only is added automatically). Nothing else.
  6. Tap Generate token, copy it (starts with github_pat_), paste below.
